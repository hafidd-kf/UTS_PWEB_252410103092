# FreshWash - Sistem Informasi Laundry Berbasis Web

FreshWash merupakan aplikasi sistem informasi laundry berbasis web yang dikembangkan menggunakan framework Laravel dan bahasa pemrograman PHP. Aplikasi ini bertujuan untuk mempermudah pengelolaan informasi layanan dan pesanan laundry secara terstruktur.

FreshWash memiliki beberapa fitur utama, yaitu Login untuk akses pengguna, Dashboard untuk menampilkan ringkasan informasi laundry, Pengelolaan untuk mengatur data layanan dan pesanan, serta Profile untuk menampilkan informasi pengguna.

Dalam pengembangannya, aplikasi ini menerapkan Route, Controller, dan Blade Template. Data layanan dan pesanan disimpan menggunakan array sebagai penyimpanan sementara tanpa menggunakan database MySQL.

Project ini dibuat sebagai penerapan materi Pemrograman Web dalam membangun aplikasi berbasis Laravel.
